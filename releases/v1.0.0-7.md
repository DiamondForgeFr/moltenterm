## What this version brings

Each workspace now has its own sidebar in place of the tab bar. You switch workspaces by swiping, with the dots, or with ⌥1 to ⌥9. On first launch, MoltenTerm helps you choose your agents, create your project and build your first view.

### Workspaces, views and projects

- A view can be temporary, pinned in its workspace or pinned everywhere. Change its state from its menu or by dragging it, and undo the change if needed.
- A workspace can hold several projects. Each project keeps its folder and code repository, and pinned views follow the project you are working in.
- The 360 view now has a tab strip you can use from the keyboard (Ctrl+Tab, numbers, reopen in place). Narrow windows switch to it and float the sidebar.
- Shortcuts follow browser habits: ⌘T opens a panel, ⌘N a new view and ⌘L the top field. ⌘W returns to the previous view and ⌘Z reopens it. Hold ⌘ to see the shortcuts for what is on screen.
- The library button at the bottom left opens workspaces, panels, settings and Materials. Materials keeps what agents showed you, with previews, and can search past sessions.

### Agents and pull requests

- The agent catalog lists every subscription coding CLI. Each agent has a page with its profile, prices and what works with it, plus one-click install and sign-in through the agent's own CLI.
- When an action does not work with the current agent, MoltenTerm says why.
- Codex sessions and sub-agents now appear in the sidebar, the companion and Integration, as Claude Code's do. Finished sub-agents leave on their own.
- The Integration panel (formerly Reviews) groups pull requests by whose turn it is and suggests a merge order. It can run a branch's version and open it in the browser, and Resume sends the work back to the agent that owns it.
- The Release menu walks you through setting up a release pipeline step by step, in plain words, with an agent beside it to answer questions.

### Look and settings

- The new Coulée theme is the default. A light theme is available, and each workspace can set its own opacity, blur and texture.
- Settings open inside the library, and each block says what it applies to. Keep-awake lives in Preferences › Energy, and a coffee cup shows while it is on.
- The file panel stays inside the project folder, lists folders first and hides hidden files. It can also show an agent's search results.
- Updates offer release candidates only if you turn on "Also get release candidates".

Sharing a page with an agent and the agents' link to MoltenTerm now keep working after a restart. A window no longer goes blank after you delete a workspace or the window's page crashes.
