## What this version brings

MoltenTerm can now review pull requests: you read a pull request, ask questions about it, comment and merge it without leaving the app. The interface is also available in English and French. It follows your system language, and you can change it in Settings.

### Review pull requests
- A Reviews view lists the pull requests waiting for your review. Its Review tab shows each pull request's files and their diff.
- A briefing in the AI panel covers what the pull request does, why, its risks and what was tested.
- Select lines to ask the AI about them or to comment on them. Answers stay as cards on their lines, and you can keep the explanations as notes for each project.
- Comments are drafted and discussed in your language, then published as one GitHub review in the project's language. Restart work gives the published comments to an agent.
- Validate rebases and merges the pull request. It then marks the ticket done and removes the worktrees and the branch. The `molten review` commands do the same from a terminal.

### Languages and layout
- Language packs and an "add a language" morph add more interface languages.
- The 360 view keeps a fixed first column next to a scrolling row of panels. It has a radar to move between panels and a pin button to keep a panel in the fixed column.
- Side panels reopen at the size you last set.
- Settings and the workspace editor have a new look. Workspace colours can come from the project's logo, with gradients and 24 presets.

### Agents and projects
- Each agent has a first name, shown in its pane header, and you can hand work to another agent by that name. A system notification asks for your approval when MoltenTerm is in the background.
- Click the model or the effort in the pane header to change it. The effort can also be changed from the command panel.
- You can share an open browser tab with an agent. Agents at work shows each agent's model, effort and the ticket's complexity.
- The companion opens on recent topics and agents at work, with compact plan usage. The changed files are collapsed and have a filter.
- The next station chip shows its due date. The Project header has a Deploy to shortcut, and the CI/CD widget lists the project's jobs.

Also fixed: the companion now follows the new session after /clear, the review panel no longer covers the terminal below it, and Clean branches finds branches merged long ago with rebase-and-merge.
