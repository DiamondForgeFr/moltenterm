## What this version brings

MoltenTerm 1.0.0 is the first public release: a terminal workspace for coding agents, built on Wave Terminal, that you reshape by asking the agent you already use. It ships no AI of its own.

### Workspaces and terminals

- A workspace rail with colours, icons and groups: drag to reorder, hold the pencil to edit a workspace.
- Split any panel, then choose what it shows; drag a panel to split, and open any widget from the command panel.
- Local terminals survive a restart, and each terminal can work in its own git worktree.
- MoltenTerm asks before a terminal, a window or a workspace that still runs something is closed.

### Coding agents

- Claude Code and Codex are set up at launch: their state shows in panes, tabs and the rail, and what needs you reaches the notification center.
- The agent companion follows the terminal's session, and the usage page shows each agent's plan limits.
- Coffee mode keeps the computer awake and approves the agents' permission requests while you are away.
- The browser panel opens the links of terminal programs, and agents can drive it, with your permission on each site.

### Projects and mods

- Mission Control links a workspace to its project: an overview with a line map, the local CI, builds and releases.
- Mods change MoltenTerm while it runs, with history, undo and a safe mode; the `molten` command does from a terminal what the interface does.

Switching workspaces, waking the computer or coming back to a hidden tab no longer leaves a blank window, and MoltenTerm stays light with many workspaces open.
