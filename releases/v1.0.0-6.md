## What this version brings

You can validate a pull request while its CI is still running. Validated pull requests now wait in a merge queue and merge themselves once green, in the suggested order. The Sessions view also shows who each session is, where it runs and what it works on.

### Reviews and merging

- Validate is available while checks run, and the Reviews list shows the merge queue.
- A red check that GitHub does not require no longer blocks Validate. You are asked to confirm instead.
- The Reviews rail icon shows the number of open draft pull requests in a grey badge.
- The Review AI panel's menu offers the session agent's options. Its session terminal stays hidden until you choose to show it.
- In the agent choice dialog, clicking an option only selects it. The Validate button starts the agent.

### Sessions and branches

- The Sessions table shows each session's agent name, model, origin, ticket, pull request and the session that handed it work. It offers Join, Interrupt, Stop and Update.
- The Sessions table marks outdated sessions and merged pull requests.
- Clean branches names the session holding a merged branch's worktree and shows main branches in their own colour.

### Fixes

This version fixes an app crash, an interrupted agent turn staying "working" (which refused Model and Effort changes), an empty slot in a magnified panel's header, and a pull request signature hidden under the docked agent bar.
