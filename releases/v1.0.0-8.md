## What this version brings

Pages an agent opens now appear in MoltenTerm's own browser, and the 360 carpet scrolls to show them. Web page bookmarks are now kept per project, and agents can read them.

### Browsing and materials

- Agents open pages in MoltenTerm's browser by default. When an agent opens or navigates a page, the carpet scrolls to it.
- The web page panel and Settings > Browser keep bookmarks for each project. Agents can read their descriptions with `molten bookmarks list`.
- Materials filter by project and show real previews on a full-width grid. A selected material opens in a panel, and a recovered one belongs to the project where its session started.

### The 360 view

- A view's icon shows one mark for each screen region. The 360 carpet's icon is a turning cube.
- An add-panel slot fills the space at each end of the carpet, and the last panel no longer has a width handle.
- Thumbnails are saved for each panel and page, so hidden pages stay recognisable. A blank page or a floating card is no longer captured.
- The 360 tab strip uses one line per meaning, and the icon colour shows the panel type.

### Safety and updates

- A terminal now sees only its own workspace. This covers terminal output, screenshots, AI panel context and workspace settings.
- SSH and WSL hosts can no longer run commands or open anything on this computer. A server asks before it touches your files, and a remembered Allow covers only one folder.
- Check for updates now checks right away instead of waiting for the daily check.

Also fixed: new terminals and file panels open in the project folder, Integration cards show the right agent activity, the next station keeps its milestone during a GitHub outage, and the workspace dots are centred.
