## What this version brings

Reviews can now plan a batch of merges. It shows which open pull requests a merge would put in conflict and suggests the order that reruns the fewest CI runs. It can also hand a selection to an agent that merges them in that order. The 360 view now opens on demand from the tab button, and the panel menu adds a panel on the left or right.

### Reviews
- An agent merges your selected pull requests in the suggested order and rebases only the ones that conflict.
- A failed CI check now shows as failed, and you can rerun it or have an agent investigate it.
- Each row shows the upcoming branches and the agent working on each pull request. Validate opens its sheet in place.
- The Reviews badges on the rail count pull requests to review and pull requests ready to merge separately.
- When you start an agent for a rebase or Restart work, it asks whether to work out of sight or with you instead of opening a tab.

### Panels and layout
- A terminal width you drag becomes a minimum that no terminal goes below.
- The 360 view offers to add a panel at each end, and keyboard overlays bring an off-screen panel into view.
- The edge split handles are gone. Split from the right-click menu or with the shortcuts.
- A magnified panel has no close button, only the button that puts it back.

### Agents and interface
- Codex terminals show their model, reasoning effort and first prompt.
- An agent handoff request no longer expires before you answer it. It opens the notification panel and says when to press Enter.
- A finished agent stays green until you have seen it.
- The French interface now covers the Files panel, the Processes view, the editor menus, notifications, board statuses and server messages.
- Default workspace names use the interface language, and a new workspace opens its edit sheet on the name.

Also fixed: garbled characters in a terminal open beside another, and local CI, review and build workspaces that kept failing once git lost track of them.
