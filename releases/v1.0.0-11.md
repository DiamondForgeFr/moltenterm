## What this version brings

Every download MoltenTerm makes, including the in-app update, now appears in Brokk's Downloads. MoltenTerm also does less work in the background, especially while several agents run at once.

### Downloads and Brokk

- The in-app update and the Files panel's Download both show in Brokk's Downloads.
- Brokk no longer comes, and no toast appears, for something you already have in view.
- Brokk's visit, his badge and the way he reports a blocked agent work as expected.

### Usage and agents

- In the Companion's usage grid, each day's block shows how much of that day's share has been used. The % sign appears where the grid has room for it.
- Agent cards say how far each agent has been tried with MoltenTerm.
- A permission card now gives you a way to the terminal.

### Lighter in the background

- Brokk is animated only where he can be seen.
- Hidden views stay quiet and catch up once when you show them again.
- MoltenTerm uses less processor time while several agents work, because it reads only the files and transcripts that changed.
- Menus that came from Wave now appear in French when the interface is in French.
