## What this version brings

Reviews now let you choose which installed coding agent does the work. They also list recently merged pull requests with who made, reviewed and merged each one. Panel layout takes less effort: one click on the tab bar makes all panels the same width.

### Reviews and merges

- Pick the coding agent in any panel that starts one. Each project keeps its own choice, with a global default, and you can switch for a single run in the agent choice dialog.
- A Recently merged section shows when each pull request was merged and by whom, and which release carries it.
- Pull requests carry the agent who made them (first name, model and effort) and the reviewer, both in MoltenTerm and on GitHub.
- Investigate and fix on a failed CI check now fixes, rebases or reruns the pull request. It turns green only once the checks pass.
- After a merge, your local working branch catches up with the remote, or MoltenTerm tells you why it could not. Clean branches also removes the worktrees of merged pull requests and recognises branches that were rebased before merging.

### Layout and tabs

- One click on the tab bar makes the tab's panels equal in width. A long press keeps them equal as the layout changes.
- In the 360 view, the first column keeps its minimum width whatever panels it holds. It can still be resized on a narrower window, and its toggle has a clearer icon.
- Closing a tab that was opened from another tab takes you back to that tab.

### Accessibility

- Screen readers can follow live terminal output, and assistive tools can close a tab without the hold.
- Dialogs keep keyboard focus inside while open and give it back when they close. Error text uses colours that are easier to read.

Also fixed: merged pull requests now leave the review list right away, batch merges no longer wait forever after a rebase, and Settings keeps the last slider change. Undoing a mod keeps executable permissions, Secrets keeps your unsaved edits, and the window no longer stops responding to clicks.
