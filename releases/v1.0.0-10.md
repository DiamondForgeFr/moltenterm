## What this version brings

The Files panel now handles documents it cannot display: Word, Excel and PowerPoint files no longer open as text, and any file can be copied in one click to paste into another app. The Integration panel also follows pushes and hand-offs as they happen, instead of showing a card that no longer matches the pull request.

### Files and usage

- Copy file puts the file shown in the Files panel on the clipboard, ready to paste elsewhere.
- Office documents and other files the panel cannot show get a clear no-preview state, so they can no longer be damaged by saving them as text.
- The Companion's usage grid has a legend and a short explanation, and its day blocks use the full width of the row.

### Integration and agents

- Integration cards update after a push. Resume and Rebase check the pull request before handing it off, and the card says when it changed or was already handed off.
- A pull request the merge queue stopped on a CI timeout offers Try again once its checks pass.
- An agent waiting on its own background command shows as working, not as waiting for you.

### Safety and openness

- A terminal reaches only the durable sessions of its own workspace.
- SSH and WSL hosts can no longer read or replace this computer's secrets or read API tokens.
- Background agents stay read-only and away from the repository's settings. Clipboard writes from a terminal are accepted only from the focused one.
- About opens the open-source licences of everything the app ships, and Settings no longer links to another product's documentation.

Several defects that could stop the background service without explanation are also fixed.
