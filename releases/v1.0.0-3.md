## What this version brings

You can now take a pull request from draft to merged without leaving MoltenTerm. The Reviews list shows drafts and upcoming conflicts, and Validate merges with whichever method the repository allows. You can also split a panel on any of its four sides and see where the new panel will go before you choose its content.

### Reviewing and merging
- Draft pull requests appear in Reviews. You can open one for analysis, then mark it ready for review.
- From a row in Reviews you can validate a pull request, see conflicts coming, or ask the agent to rebase. After a merge, only the pull requests that now conflict get a rebase request.
- Validate merges with the methods the repository allows: merge commit, squash or rebase. It remembers your last choice and shows each step and what it will do.
- Before cleanup removes anything, it says what you would lose. It keeps a worktree that a panel still uses and offers Show the panel.
- After the merge, the review tab shows Validated with a done mark and offers to close. The rail's Reviews icon counts pull requests waiting for review and those ready to merge.

### Layout
- Split placement mode shows a preview on the panel you are splitting, then lets you choose the content.
- Settings and Tips fill a wide panel, with their sections arranged in columns.
- In the 360 view, the radar shows the visible area as a window, with an eye on hover.

### Privacy and safety
- Pages in the browser panel ask before using the camera, microphone or location, and the question stays readable in a narrow panel.
- Coffee mode never automatically approves a program read from standard input.
- Handoff briefs never quote secrets, and the browser log keeps only the host of each address.
- Review sessions do not load the agent settings of the pull request under review.

Also fixed: horizontal scrolling over an unfocused panel now moves the 360 view, and the opening-workspace page and session ages now follow your interface language.
