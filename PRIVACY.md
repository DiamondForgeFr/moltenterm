# Privacy

MoltenTerm sends no usage data and has no account. It connects to the network only for what you ask: links you open,
GitHub for a project you link to Mission Control, and the release feed.

MoltenTerm ships no AI and never touches your agents' credentials. The coding agents you run in it (Claude Code, Codex,
Gemini CLI or any other) connect to their own services under their own terms, exactly as in any other terminal.
